When a TGV is late, who is to blame: the trains, the tracks, or the passengers?

The original project is an interactive Bokeh server app that works as the slide deck of our talk: a hook, a map of the rail network, then four acts that follow Shneiderman’s mantra, overview first, zoom and filter, then details on demand (Shneiderman 1996). This chapter tells the same story for the portfolio. Cleaning decisions

The full log of ambiguities and decisions lives in the project’s DATA_NOTES.md. The ones that matter for this chapter:

  • % late is computed from counts: late trains ÷ (planned − cancelled). Yearly and group figures sum the counts first, then divide, never averaging percentages.
  • Months with zero planned trains are dropped (nothing to measure).
  • Rows whose six cause shares are all zero keep their counts but are left out of the cause analysis.
  • Cause shares are weighted by each row’s number of late trains, so a 3-train route does not weigh as much as a 300-train one.
  • Causes are compared on full years 2018–2025: the categories appear to change around May 2026.
  • The national file has no counts, so its yearly rate is the mean of monthly percentages, an approximation we state as such.
Show code 
national <- read_sncf("national") |>
  transmute(date = ym(Date), pct_late = 100 - `Régularité composite`)

axes <- read_sncf("axes") |>
  transmute(date = ym(Date), axis = Axe, pct_late = 100 - `Régularité composite`)

foreign <- c("BARCELONA", "MADRID", "FRANCFORT", "STUTTGART",
             "ZURICH", "LAUSANNE", "GENEVE", "ITALIE")

routes <- read_sncf("routes") |>
  transmute(
    date = ym(Date), service = Service,
    departure = `Gare de départ`, arrival = `Gare d'arrivée`,
    planned = `Nombre de circulations prévues`,
    cancelled = `Nombre de trains annulés`,
    late = `Nombre de trains en retard à l'arrivée`,
    External = `Prct retard pour causes externes`,
    Infrastructure = `Prct retard pour cause infrastructure`,
    `Traffic management` = `Prct retard pour cause gestion trafic`,
    `Rolling stock` = `Prct retard pour cause matériel roulant`,
    `Station management` = `Prct retard pour cause gestion en gare et réutilisation de matériel`,
    Passengers = `Prct retard pour cause prise en compte voyageurs (affluence, gestions PSH, correspondances)`
  ) |>
  filter(planned > 0) |>
  mutate(
    ran  = planned - cancelled,
    year = year(date),
    type = case_when(
      departure %in% foreign | arrival %in% foreign ~ "International",
      str_starts(departure, "PARIS") | str_starts(arrival, "PARIS") ~ "To/from Paris",
      TRUE ~ "Province to province"
    )
  )

national_yearly <- national |>
  group_by(year = year(date)) |>
  summarise(pct_late = mean(pct_late), months = n(), .groups = "drop")

latest      <- national_yearly |> slice_max(year)
last_month  <- max(national$date)
worst_prev  <- national_yearly |> filter(year < latest$year) |> slice_max(pct_late)

Punctuality is getting worse: 2026 is the worst year in the data (Figure 5.1). Act 3 · It’s where, not how far

In the app, a route map and a duration-versus-delay scatter share one data source, so selecting routes on either highlights them on both. The first hypothesis, long routes are late more often, did not hold: trip duration barely relates to the share late. What does matter is where a route runs.

Show code 
routes |>
  group_by(year, type) |>
  summarise(pct_late = 100 * sum(late) / sum(ran), .groups = "drop") |>
  ggplot(aes(year, pct_late, colour = type)) +
  geom_line(linewidth = .9) +
  geom_point(size = 1.6) +
  scale_colour_manual(values = c(`Province to province` = accent,
                                 `To/from Paris` = "#0072B2",
                                 International = context)) +
  scale_y_continuous(labels = label_percent(scale = 1)) +
  scale_x_continuous(breaks = pretty_breaks()) +
  labs(x = NULL, y = "Trains late", colour = NULL)

Routes between two regional cities that do not go through Paris are late more often (19.6 %) than routes to or from Paris (13.9 %), and the gap holds in every year from 2018 to 2025, by 2.7 to 8.7 points (Figure 5.3). The data shows where delays concentrate, not why.

Act 4 · Who’s to blame?

Show code 
cause_cols <- c("External", "Infrastructure", "Traffic management",
                "Rolling stock", "Station management", "Passengers")
groups <- c(External = "External", Infrastructure = "Tracks",
            `Traffic management` = "Tracks", `Rolling stock` = "Trains",
            `Station management` = "Trains", Passengers = "Passengers")

causes <- routes |>
  filter(year %in% 2018:2025, rowSums(across(all_of(cause_cols))) > 0) |>
  pivot_longer(all_of(cause_cols), names_to = "cause", values_to = "share") |>
  mutate(group = factor(groups[cause], levels = c("Tracks", "Trains", "External", "Passengers")),
         late_trains = share / 100 * late)

cause_total <- causes |>
  group_by(group) |>
  summarise(n = sum(late_trains), .groups = "drop") |>
  mutate(pct = 100 * n / sum(n))
pct_of <- \(g) number(cause_total$pct[cause_total$group == g], accuracy = 1)
Show code 
causes |>
  group_by(year, group) |>
  summarise(n = sum(late_trains), .groups = "drop") |>
  group_by(year) |>
  mutate(pct = n / sum(n)) |>
  ggplot(aes(factor(year), pct, fill = fct_rev(group))) +
  geom_col(width = .75, colour = "white", linewidth = .4) +
  scale_fill_manual(values = c(Tracks = "#D55E00", Trains = "#0072B2",
                               External = "#009E73", Passengers = "#CC79A7"),
                    breaks = c("Tracks", "Trains", "External", "Passengers")) +
  scale_y_continuous(labels = label_percent(), expand = c(0, 0)) +
  labs(x = NULL, y = "Share of late trains", fill = NULL)

Mostly the tracks (Figure 5.4). Weighted by late trains, tracks (infrastructure + traffic management) account for 44 % of delays, trains (rolling stock + station management) 27 %, external causes 21 % and passengers 8 %. Two caveats: SNCF attributes the causes itself, and the “tracks first” result depends on our grouping, since no single SNCF category dominates on its own.

Visualisation and accessibility choices

  • One accent colour per chart: grey for context, vermillion for the series the story follows.
  • Act 3 colour scales are fixed at 0–30 % late (ColorBrewer YlOrRd), so a colour means the same thing whatever year is selected.
  • Two accessibility approaches: the cause chart does not rely on colour alone (Okabe-Ito palette checked with a colour-vision-deficiency simulator, white gaps, legend and optional hatch patterns); the punctuality chart has text alternatives (a written summary generated from the data, detailed tooltips and a drawer with the full data table).
  • Iterated on feedback: after a review with the teacher, the six axis panels became one comparable chart, the route-type dropdown became a carousel of cards, and the map colour scale moved from a single red hue to a sequential yellow-to-red scale.

Limitations

  • Monthly totals, not individual trains.
  • Delay causes are self-reported by SNCF; the categories seem to change in 2026 and the passenger share jumps suddenly in January 2021.
  • The national and route-level rates differ in level (for example 13.4 % vs 15.1 % in 2025) for reasons we could not confirm, so they are never compared directly.
  • Correlation is not causation: the charts show where and when delays happen, not why.

`r sum(worst_axis$year >= 2022)` full years since 2022.

## Act 3 · It's where, not how far

```{r}
#| label: tgv-route-types
#| include: false

type_rates <- routes |>
  group_by(type) |>
  summarise(pct_late = 100 * sum(late) / sum(ran), routes = n_distinct(paste(departure, arrival)),
            .groups = "drop")
prov  <- filter(type_rates, type == "Province to province")
paris <- filter(type_rates, type == "To/from Paris")

gap <- routes |>
  filter(year <= 2025, type != "International") |>
  group_by(year, type) |>
  summarise(p = 100 * sum(late) / sum(ran), .groups = "drop") |>
  pivot_wider(names_from = type, values_from = p) |>
  mutate(gap = `Province to province` - `To/from Paris`)
```

In the app, a route map and a duration-versus-delay scatter share one data
source, so selecting routes on either highlights them on both. The first
hypothesis, *long routes are late more often*, did not hold: trip duration
barely relates to the share late. What does matter is **where** a route runs.

Routes between two regional cities that do not go through Paris are late more
often (`r number(prov$pct_late, accuracy = 0.1)` %) than routes to or from
Paris (`r number(paris$pct_late, accuracy = 0.1)` %), and the gap holds in
**every year** from 2018 to 2025, by
`r number(min(gap$gap), accuracy = 0.1)` to

shows *where* delays concentrate, not *why*.

## Act 4 · Who's to blame?

```{r}
#| label: tgv-causes

cause_cols <- c("External", "Infrastructure", "Traffic management",
                "Rolling stock", "Station management", "Passengers")
groups <- c(External = "External", Infrastructure = "Tracks",
            `Traffic management` = "Tracks", `Rolling stock` = "Trains",
            `Station management` = "Trains", Passengers = "Passengers")

causes <- routes |>
  filter(year %in% 2018:2025, rowSums(across(all_of(cause_cols))) > 0) |>
  pivot_longer(all_of(cause_cols), names_to = "cause", values_to = "share") |>
  mutate(group = factor(groups[cause], levels = c("Tracks", "Trains", "External", "Passengers")),
         late_trains = share / 100 * late)

cause_total <- causes |>
  group_by(group) |>
  summarise(n = sum(late_trains), .groups = "drop") |>
  mutate(pct = 100 * n / sum(n))
pct_of <- \(g) number(cause_total$pct[cause_total$group == g], accuracy = 1)
```

```{r}
#| label: fig-tgv-causes
#| fig-height: 4.5
#| fig-cap: "Delay causes as attributed by SNCF, weighted by the number of late trains (2018–2025). Okabe-Ito colour-blind-safe palette."

causes |>
  group_by(year, group) |>
  summarise(n = sum(late_trains), .groups = "drop") |>
  group_by(year) |>
  mutate(pct = n / sum(n)) |>
  ggplot(aes(factor(year), pct, fill = fct_rev(group))) +
  geom_col(width = .75, colour = "white", linewidth = .4) +
  scale_fill_manual(values = c(Tracks = "#D55E00", Trains = "#0072B2",
                               External = "#009E73", Passengers = "#CC79A7"),
                    breaks = c("Tracks", "Trains", "External", "Passengers")) +
  scale_y_continuous(labels = label_percent(), expand = c(0, 0)) +
  labs(x = NULL, y = "Share of late trains", fill = NULL)
```

Mostly the tracks (@fig-tgv-causes). Weighted by late trains, **tracks**
(infrastructure + traffic management) account for `r pct_of("Tracks")` % of
delays, **trains** (rolling stock + station management) `r pct_of("Trains")` %,
**external** causes `r pct_of("External")` % and **passengers**
`r pct_of("Passengers")` %. Two caveats: SNCF attributes the causes itself, and
the "tracks first" result depends on our grouping, since no single SNCF
category dominates on its own.

## Visualisation and accessibility choices

- **One accent colour per chart**: grey for context, vermillion for the series
  the story follows.
- **Act 3 colour scales are fixed** at 0–30 % late (ColorBrewer YlOrRd), so a
  colour means the same thing whatever year is selected.
- **Two accessibility approaches**: the cause chart does not rely on colour
  alone (Okabe-Ito palette checked with a colour-vision-deficiency simulator,
  white gaps, legend and optional hatch patterns); the punctuality chart has
  text alternatives (a written summary generated from the data, detailed
  tooltips and a drawer with the full data table).
- **Iterated on feedback**: after a review with the teacher, the six axis
  panels became one comparable chart, the route-type dropdown became a
  carousel of cards, and the map colour scale moved from a single red hue to a
  sequential yellow-to-red scale.

## Limitations

- Monthly totals, not individual trains.
- Delay causes are self-reported by SNCF; the categories seem to change in
  2026 and the passenger share jumps suddenly in January 2021.
- The national and route-level rates differ in level (for example
  `r number(national_yearly$pct_late[national_yearly$year == 2025], accuracy = 0.1)` %
  vs `r number(with(filter(routes, year == 2025), 100 * sum(late) / sum(ran)), accuracy = 0.1)` %
  in 2025) for reasons we could not confirm, so they are never compared
  directly.
- Correlation is not causation: the charts show where and when delays happen,
  not why.
